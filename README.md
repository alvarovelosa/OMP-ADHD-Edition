# OMP (ADHD Edition) 🧠⚡

Fork of [oh-my-pi](https://github.com/can1357/oh-my-pi). Go there for the wall of text. — docs, install, features, benchmarks. This README only talks about the bits *we* bolted on.

Who is this for > ADHD people > that need to see things to remember > that long session names scrambles their brain > that lose flow when trying settings > tested web-ui´s and IDE´s but prefer nerd font!

## What we added >

- 🎛️ **Web Settings Panel** — stop editing JSON by hand like it's 2004. Click things at `http://localhost:3847/#/settings`. 
- 📼 **Sessions Dashboard** — browse, archive, delete, and re-read old sessions as actual readable cards, not a wall of raw JSON.
- 🔢 **Numbered Sessions** — every session gets a stable `#N` so "which one was that again?" has an answer. `omp --resume <N>` / `/resume #N`.

Try it > in your terminal > "omp stats" > auto starts server > boom.

That's it. That's the whole README. No meds needed.
