# OMP (ADHD Edition)

Fork of [oh-my-pi](https://github.com/can1357/oh-my-pi). Everything else — docs, install, features, benchmarks — lives there.

## What we added

- **Web Settings Panel** — visual config editor at `http://localhost:3847/#/settings`
- **Sessions Dashboard** — browse, archive, delete, & read session transcripts as readable cards
- **Numbered Sessions** — stable `#N` session IDs (`omp --resume <N>` / `/resume #N`)
